    CastorEDC.Test (ExCastorEDC v1.0.0-rc.1)

    Copy Markdown View Source

    A client for tests, whose responses the test writes and whose requests it can inspect.

    client/2 builds a client from CastorEDC.new/1 whose Req adapter never touches the network: it answers with the response the test gives and sends the request it would have made to the test process, where requested/1 reads it back. Because only the adapter is replaced, every request and response step still runs, including authentication, rate limiting and decoding into structs.

    client = CastorEDC.Test.client(CastorEDC.Test.json(%{"study_id" => "S1"}))
{:ok, study} = CastorEDC.Studies.get_study(client, "S1")

request = CastorEDC.Test.requested()
assert request.url.path == "/api/study/S1"

    A function answers each request in turn, which suits operations that page:

    client =
  CastorEDC.Test.client(fn request ->
    case request.url.path do
      "/api/study/S1/site" -> CastorEDC.Test.json(sites)
      "/api/study/S1/participant" -> CastorEDC.Test.json(participants)
    end
  end)

) :: Req.Request.t()

    A client that answers every request with response.

    response is a Req.Response, an exception, or a function that takes the Req.Request and returns one of those. Retries are off, an access token is set and the server is https://data.castoredc.com, unless options says otherwise; the options go to CastorEDC.new/1.

    The requests go to the process that built the client.
