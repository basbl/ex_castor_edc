    CastorEDC.DataPoints

    The values collected for participants: reading them per study, per participant or per survey, repeating data or survey package instance, and writing them one at a time or in bulk. Values are strings; see CastorEDC.FieldValue for decoding them by field type.

    CastorEDC.Error

    A failed request: one the API refused, one that never got an answer, or one the client gave up on.

    CastorEDC.Export

    Batch exports: a study's data, structure, queries and more, as files.

    CastorEDC.Exports

    Batch exports: queuing them, listing them with their status, and downloading the result. CastorEDC.Export does all three in one call.
