    CastorEDC.Countries (ExCastorEDC v1.0.0-rc.1)

    Copy Markdown View Source

    The countries Castor EDC knows, for site and participant addresses.

    Operations

    • get_country/3 - Retrieve a single Country
    • list_countries/2 - Retrieves the list of all countries

    Every operation returns {:ok, result} or {:error, %CastorEDC.Error{}}, and has a ! variant that returns the result or raises the error.
