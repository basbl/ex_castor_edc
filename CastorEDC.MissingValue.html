    CastorEDC.MissingValue (ExCastorEDC v1.0.0-rc.1)

    Copy Markdown View Source

    A value the user marked as missing, with the reason they gave.

    Instead of a value, a field can hold one of five missing-data codes, stored as ##USER_MISSING_95## to ##USER_MISSING_99##. CastorEDC.FieldValue.decode/2 turns them into this struct:

    CodereasonMeaning
    95:measurement_failedMissing (measurement failed)
    96:not_applicableMissing (not applicable)
    97:not_askedMissing (not asked)
    98:asked_but_unknownMissing (asked but unknown)
    99:not_doneMissing (not done)

    Exports write the codes as -95 to -99 in numeric columns, and as the dates 1 January 2995 to 2999 in date columns.
